# Tunara landing page

A standalone responsive landing page for Tunara, a local-first terminal workspace. Includes a dark-mode product page, CSS and JavaScript in `index.html`, and the official Tunara app icon referenced from the upstream repository.

## Preview

Open `index.html` in a browser or serve this directory with any static HTTP server.

## Deploy

This is a static frontend suitable for GitHub Pages or Cloudflare Pages. For Cloudflare Pages, connect this repository and use the repository root as the build output directory; there is no build command. For GitHub Pages, select the `main` branch and root directory in Pages settings.

Release/source links and product copy are in `index.html`. Official icon source: `assets/brand/tunara-app-icon-preview-128.png` in https://github.com/24kHandsome1201/tunara.
