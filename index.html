01 · Workspace

Real terminals. Real machines.
One workspace.

Tunara groups local and SSH sessions by the project and machine they belong to, so you always know which box you’re in. It works alongside the tools you already trust and leaves every action with you.

01 / CONTEXT

Grouped by project, not by tab

Local and SSH sessions live under the project and machine they belong to. Find the right shell without scanning a flat list.

02 / AWARENESS

Notice when your agent needs you

See sessions where a supported coding agent is waiting. Tunara informs; you decide what happens next.

03 / REVIEW

Read-only review beside the shell

Inspect Git changes and preview files in context. The inspector never stages, commits, or pushes.

02 · Agent awareness

Know when a coding agent
is waiting on you.

Lightweight status awareness for agents you already run in your terminals. No chatbot, no orchestration, no automatic actions.
